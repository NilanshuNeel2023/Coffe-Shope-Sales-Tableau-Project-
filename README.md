# Coffee Shop Sales Analysis Dashboard | Tableau Project
## Project Overview

This project is a comprehensive Coffee Shop Sales Analysis Dashboard developed using Tableau to analyze sales performance, customer purchasing behavior, product trends, and operational insights for a coffee shop business.

The dashboard transforms raw transactional data into interactive visual insights that help businesses understand:

- Sales performance trends
- Peak business hours
- Best-selling products
- Customer purchasing patterns
- Store-wise sales performance
- Category contribution analysis
- Revenue optimization opportunities

This project demonstrates strong expertise in:

- Data Visualization
- Business Intelligence Reporting
- Dashboard Storytelling
- KPI Development
- Interactive Dashboard Design
- Sales Trend Analysis
- Business Performance Monitoring

## Business Problem

Coffee shop businesses generate large amounts of daily transactional data. Without proper analysis, it becomes difficult to understand:

- Which products generate the highest revenue
- Which hours drive the most sales
- Which store locations perform best
- Customer buying patterns
- Monthly and daily sales trends

This Tableau dashboard helps stakeholders make data-driven decisions to improve:

- Product strategy
- Inventory planning
- Staff allocation
- Sales performance
- Business profitability

## Business Questions Solved in the Project
## Sales Performance Analysis
1. What is the total revenue generated by the coffee shop?
2. What are the monthly sales trends?
3. Which day generates the highest sales?
4. Which month recorded the highest revenue?

## Time-Based Sales Analysis
1. Which hour of the day has the highest sales?
2. What are the busiest business hours?
3. Compare morning vs evening sales performance

## Product Performance Analysis
1. Which product category generates the highest revenue?
2. What are the top-selling products?
3. Which products underperform?
4. Compare beverage vs food sales contribution

## Store Location Analysis
1. Which store location generates the highest sales?
2. Which store receives the highest number of orders?
3. Compare average sales across stores

## Customer Purchasing Trend Analysis
1. What are the daily sales trends?
2. Which products are frequently purchased together?
3. How does customer demand vary by season?
